    Fuzzy, domain first

    gh pr finds the GitHub pull request. Words can come in any order. Domain ranks above title, title above the rest of the URL, and matched letters are highlighted.

    gh pr

      Flip back with two keys

      The previous tab is already selected. CtrlE then Enter takes you back. AltZ does it without opening anything.

      Search tabs, or type / for more

        Every window

        All open tabs in all windows, most recently used first. A tab in another window gets a small window badge, and Enter focuses that window.

          Tabs, bookmarks, history

          Type / to pick a scope. Bookmarks and history (last 90 days) stay off until you turn them on in the options, and the browser asks first.

              Nine keys, and you know it all.

              Open

              CtrlE
              Open TabNow on the current page. Press it again to close.
              AltZ
              Jump to the previous tab. No panel, press again to flip back.
              AltT
              Switch between light and dark.

              Move

              ↑↓orCtrlJK
              Move through the results. The list wraps at both ends.
              Enter
              Switch to the selected tab, in any window.
              Esc
              Dismiss. Clicking the dimmed page does the same.

              Search

              /
              Pick a scope: /t tabs, /b bookmarks, /h history.
              Ctrl⌫
              Close the selected tab and stay in the list.
              CtrlU
              Clear the query. Press again to clear the scope.

              On macOS, Ctrl becomes Cmd for the open key and for closing a tab.

              No network requests. Ever.

              No account, no analytics. Your tabs are searched inside the browser and never leave it.

[00] TABNOW

Every tab,
one keystroke away.

TabNow is a fuzzy finder for your open tabs. Press Ctrl+E, type a few letters, hit Enter. You are on the tab. Built for 30 to 200 open tabs.

$ git clone tabnow $ try the demo

Chrome 121+, Edge, Brave, Opera, Vivaldi, Arc. MIT. Web Store: coming soon.

    [02] FEATURES

    Six things it does.

    1Find any tab

    Ctrl+E, a few letters, Enter. Most recent first, previous tab preselected, so Ctrl+E Enter flips back.

    2Fast, fuzzy

    "gh pr" finds the GitHub pull request. Every word must match. Domain beats title, title beats the rest of the URL.

    3Keyboard first

    Arrows or Ctrl+J/K to move, Ctrl+Backspace to close a tab. The mouse works too.

    4Private

    Zero network requests. No account, no analytics. Plain JS, no dependencies, open source.

    5All windows

    Tabs from other windows carry a badge. Add bookmarks and history (90 days) with /b and /h. Both are opt-in.

    6Fits your browser

    Light and dark with Alt+T. Set opacity (60 to 100 %), blur (0 to 40 px) and size (70 to 150 %) on the options page.

    [03] KEYS

    $ man tabnow

    Keyboard shortcuts
    keydoes
    Ctrl+EOpen or close the finder (Cmd+E on macOS)
    Alt+ZJump to the previous tab. Nothing opens.
    ↑ ↓ / Ctrl+J KMove selection. Wraps at both ends.
    EnterSwitch to the tab. Focuses its window if needed.
    Ctrl+BackspaceClose the selected tab, stay in the list
    /Scope menu: /t tabs, /b bookmarks, /h history
    Ctrl+UClear query. Again to clear scope.
    Alt+TLight or dark
    EscDismiss
    [04] PRIVACY

    No network requests. Ever.

    What TabNow may touch, as ls -l. Nothing here talks to a server.

    $ ls -l ./permissions
    modenamewhy
    -r--------tabsRead titles and URLs to list and switch tabs
    -r--------activeTabShow the panel on the page you are on
    -r--------scriptingDraw the overlay in the page
    -r--------faviconRead icons from the browser cache, not the web
    -rw-------storageSave your options, synced by your browser
    -r-- opt-inbookmarksOnly if you turn on /b. The browser asks first.
    -r-- opt-inhistoryOnly if you turn on /h. Last 90 days.
    ----------networkNever. No accounts, no analytics, no telemetry.

    Plain JS, ~600 lines, no dependencies. Read the source.

    [05] INSTALL

    Four steps. No store yet.

    1. Clone the repo.$ git clone https://github.com/gran-software-solutions/tabnow
    2. Open the extensions page and turn on Developer mode.chrome://extensions
    3. Click Load unpacked and pick the extension/ folder.
    4. Press Ctrl+E on any page. Check shortcuts at chrome://extensions/shortcuts if it does not open.

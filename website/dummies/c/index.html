    Why it's nice

    Six small reasons
    to stop scrolling the tab strip.

    ⚡

    Find any tab in a keystroke

    Ctrl+E, a few letters, Enter. The previous tab is preselected, so Ctrl+E Enter flips straight back. Alt+Z jumps there without opening anything.

    🔍

    Fast and fuzzy

    Type gh pr and the GitHub pull request shows up. Every word must match. Domain beats title, title beats the rest of the URL. Matched letters light up.

    ⌨

    Keyboard-only (mouse welcome)

    Arrows or Ctrl+J/Ctrl+K to move, Ctrl+Backspace to close a tab, Esc to leave. Clicking works too. We don't judge.

    🔒

    Private by design

    Zero network requests. No account, no analytics, nothing leaves your browser. Open source, plain JS, no dependencies, about 600 lines. Read it over coffee.

    🪟

    Every window, plus more

    Searches all open tabs in all windows. Tabs from other windows get a small window badge. Add bookmarks and history (last 90 days) when you want them, with /b and /h.

    🎨

    Fits your browser

    Light and dark (Alt+T), a frosted glass panel, and options for opacity (60–100 %), blur (0–40 px), size (70–150 %) and keys.

    Cheat sheet

    Ten keys. That's the whole manual.

    Chrome 121+, Edge, Brave, Opera, Vivaldi, Arc. Use Ctrl on Windows and Linux, Cmd on macOS.

    CtrlEOpen TabNow
    AltZPrevious tab, no overlay
    ↑↓Move up / down
    CtrlJ KMove, home-row style
    ↵Go to tab
    Ctrl⌫Close selected tab
    /Pick a scope
    CtrlUClear the field
    EscDismiss
    AltTLight / dark

    Scopes: /t Tabs · /b Bookmarks · /h History (last 90 days). Bookmarks and history are off by default; opt in on the options page and your browser asks permission.

    Privacy

    No network requests. Ever.

    TabNow never phones home. It asks for a few browser permissions, and here is what each one is for, in plain words.

    No accountNo analyticsNo serversMIT licensed
    tabs

    Lists your open tabs so there is something to search.

    activeTab

    Lets the panel appear on the page you are looking at.

    scripting

    Draws the overlay on that page. Nothing is read from it.

    favicon

    Shows each tab's little icon, fetched locally by the browser.

    storage

    Remembers your options and tab order on your machine.

    bookmarks

    Optional. Only if you switch on bookmark search.

    history

    Optional. Only if you switch on history search.

    Install

    Four steps, one minute.

    TabNow is not in the Web Store yet, so you load it yourself. It is easier than it sounds.

    1. Clone the repo

      git clone https://github.com/gran-software-solutions/tabnow

    2. Open extensions

      Go to chrome://extensions in Chrome, Edge, Brave or friends.

    3. Developer mode

      Flip the Developer mode switch in the top right corner.

    4. Load unpacked

      Click Load unpacked, pick the extension/ folder. Press CtrlE.

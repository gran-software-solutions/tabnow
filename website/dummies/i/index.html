Keys

Ctrl E opens it. Type a few letters. Enter takes you there. Ctrl Backspace closes the tab. Esc puts everything back.

Move with ↑ ↓ or Ctrl J Ctrl K. Clear with Ctrl U. Scope with /, then t, b or h. Flip back to the previous tab with Alt Z, no overlay at all. Switch theme with Alt T. On macOS, Cmd takes the place of Ctrl for opening and closing.

No network requests. Ever.

No account, no analytics. Nothing leaves your browser. About 600 lines of plain JavaScript with no dependencies, so you can read it before you install it.

tabs
Reads the titles and addresses of your open tabs so it can search them.
activeTab

scripting

Remembers your settings, like the theme and the close-tab key.
history, bookmarksoptional

Install it today.

Not in the Web Store yet. Needs Chrome 121 or newer, or Edge, Brave, Opera, Vivaldi or Arc.

git clone https://github.com/gran-software-solutions/tabnow.git
Open the repo
  1. Clone the repo.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the extension/ folder.
  4. Press Ctrl E on any page.Change the shortcut at chrome://extensions/shortcuts.

    Features

    Find it, then get on with it.

    TabNow is a small Chrome extension. No windows to sort, no tab groups to keep tidy.

    01

    Find any tab in a keystroke

    Ctrl+E, a few letters, Enter. The previous tab is preselected, so Ctrl+E Enter flips back.

    02

    Fast and fuzzy

    Type "gh pr" and get the GitHub pull request. Domain ranks above title, title above the rest of the address.

    03

    Keyboard first

    Arrows or Ctrl+J / Ctrl+K to move, Ctrl+Backspace to close a tab. The mouse works too.

    04

    Every window

    All open windows in one list. Bookmarks and history join in when you turn them on, with /b and /h.

    05

    Private by design

    No network requests, no account, no analytics. Nothing leaves your browser.

    06

    Fits your browser

    Light and dark, adjustable opacity, blur and size. Alt+Z jumps to the previous tab without opening anything.

    Privacy

    No network requests. Ever.

    No account, no analytics, no servers. About 600 lines of plain JavaScript with no dependencies, open source under MIT. Here is what it asks the browser for, and why.

    tabsRead titles and addresses of open tabs, so you can search them.
    activeTabShow the finder on the page you are on.
    scriptingPut the finder on that page.
    faviconShow each site's small icon.
    storageRemember your settings on this device.
    bookmarksOnly if you turn on /b. The browser asks first.
    historyOnly if you turn on /h. Last 90 days, searched locally.
    Install

    Four steps, one minute.

    Works in Chrome 121+, Edge, Brave, Opera, Vivaldi and Arc. Not in the Web Store yet.

    1. Clone the repository from GitHub.
    2. Open chrome://extensions.
    3. Turn on Developer mode.
    4. Choose Load unpacked and pick the extension/ folder.

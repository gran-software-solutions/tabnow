    02

    Six things it does.

    Find any tab in a keystroke.

    Ctrl+E, a few letters, Enter. The previous tab is preselected, so Ctrl+E Enter flips back.

    Fast and fuzzy.

    gh pr finds the GitHub pull request. Words must all match. Domain ranks above title, title above the rest of the URL.

    Keyboard only.

    Every action has a key. The mouse works too: hover selects, click switches.

    Private by design.

    Zero network requests. Nothing to sign up for. About 600 lines of plain JavaScript, open source.

    Every window.

    Tabs from all windows, most recently used first. Bookmarks and history too, when you turn them on.

    Fits your browser.

    Light and dark. A glass panel with opacity, blur and size you set.

    03

    Keys.

    Open

    Ctrl+E
    Open TabNow on the current page.
    Alt+Z
    Jump to the previous tab. No panel.

    Move

    ↑ ↓orCtrl+J / K
    Move the selection. It wraps at both ends.
    Enter
    Switch to the selected tab, in any window.

    Act

    Ctrl+⌫
    Close the selected tab and stay in the list.
    /
    Scopes: /t tabs, /b bookmarks, /h history.
    Ctrl+U
    Clear the search.
    Alt+T
    Switch light and dark.
    Esc
    Dismiss.

    04

    Privacy

    No network requests. Ever.

    No account, no analytics. Your tabs never leave the browser. These are the permissions it asks for, in plain words.

    Always

    tabs
    Read titles and addresses of open tabs, so you can search them.
    activeTab
    Show the panel on the page you are on.
    scripting
    Put that panel onto the page.
    favicon
    Show each site's icon, read from the browser.
    storage
    Remember your options.

    Only if you ask

    bookmarks
    When you turn on /b. The browser asks first.
    history
    When you turn on /h. The browser asks first.

    05

    Install in four steps.

    1. 1

      Clone the repo.

    2. 2

      Open chrome://extensions and turn on Developer mode.

    3. 3

      Click Load unpacked and pick the extension/ folder.

    4. 4

      Press Ctrl+E on any page.

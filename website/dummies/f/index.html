    Six small things it does well

    No dashboards, no tabs-as-trees. Just a quick box that finds things.

    Find any tab in a keystroke

    Ctrl+E, a few letters, Enter. The previous tab is preselected, so Ctrl+E Enter flips back.

    Fast and fuzzy

    Type gh pr and the GitHub pull request shows up. Domain ranks above title, title above the rest of the URL.

    Keyboard first, mouse welcome

    Arrows or Ctrl+J/K to move, Ctrl+Backspace to close a tab. Hover and click work too.

    Private by design

    Zero network requests. No account, no analytics. Plain JavaScript, open source, about 600 lines you can read in an evening.

    Every window, plus more

    All your windows at once. Add bookmarks (/b) and the last 90 days of history (/h) when you want them.

    Fits your browser

    Light and dark (Alt+T), a frosted glass panel. Tweak opacity, blur, size and keys on the options page.

    The cheat sheet, pocket size

    On macOS, swap Ctrl for Cmd where it matters.

    No network requests. Ever.

    No account. No analytics. Nothing leaves your browser.

    The extension asks for a few permissions. Here is what each one is for, in plain words.

    • tabs

      Reads the titles and addresses of your open tabs so it can search them, and switches or closes them.

    • activeTab

      Lets it show the search panel on the page you are looking at.

    • scripting

      Puts that panel onto the page.

    • favicon

      Shows each site's little icon, taken from your browser's own cache.

    • storage

      Remembers your settings (theme, opacity, keys) and syncs them with your browser profile.

    • history bookmarks

      Optional and off by default. Only if you switch on the scopes, and your browser asks first.

    Four steps, no sign-up

    TabNow needs Chrome 121+ or a Chromium browser of that version.

    1. Clone the repo

      git clone it from GitHub.

    2. Developer mode

      Open chrome://extensions (or brave://, edge://) and turn on Developer mode.

    3. Load unpacked

      Click Load unpacked and pick the extension/ folder.

    4. Press Ctrl+E

      Optional: check shortcuts at chrome://extensions/shortcuts. Then press Ctrl+E on any page.

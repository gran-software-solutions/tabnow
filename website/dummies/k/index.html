01What it does

TabNow is a fuzzy finder for your open tabs. Press Ctrl+E, type a few letters, hit Enter.

It searches every tab in every window. The most recently used tab comes first, and the previous one is already selected, so Ctrl+E, Enter flips you back to where you were. Type gh pr and you land on the GitHub pull request. Words can come in any order, all of them have to match, and the domain counts for more than the title, the title for more than the rest of the URL. Matched letters are highlighted.

02More than tabs

  • Bookmarks and history

    Type /b to search bookmarks, /h for history (the last 90 days), /t for tabs. Both are off until you turn them on in the options page, and the browser asks you for permission first.

  • Every window

    Tabs from your other windows show up in the same list. A small window badge on the icon tells you which ones are elsewhere.

  • Close tabs from the list

    Spot ten tabs you do not need while searching? Ctrl Backspace closes the selected one, and the list stays open.

  • Light, dark, your size

    Switch themes with Alt T. The options page sets panel opacity (60 to 100 %), blur (0 to 40 px), size (70 to 150 %) and the keys.

  • Works where you work

    Chrome 121 or newer, plus Edge, Brave, Opera, Vivaldi and Arc.

03Privacy

No network requests. Ever.

No account, no analytics, nothing leaves your browser. It is plain JavaScript with no dependencies, about 600 lines, MIT licensed and open source. You can read all of it in an afternoon, or in a coffee break.

04Install

Four steps, about a minute.

  1. Clone the repositorygithub.com/gran-software-solutions/tabnow
  2. Open chrome://extensions
  3. Turn on Developer mode
  4. Click Load unpacked and pick the extension/ folderThen press Ctrl+E on any page.

    // features

    Built for people with 80 tabs open.

    01

    Find any tab in a keystroke

    Ctrl+E, a few letters, Enter. The previous tab is preselected, so Ctrl+E Enter flips back. Alt+Z jumps there without opening anything.

    02

    Fast and fuzzy

    “gh pr” finds the GitHub pull request. Every word must match. Domain ranks above title, title above the rest of the URL. Matched letters light up.

    03

    Keyboard-only, mouse welcome

    Arrows or Ctrl+J/K to move, Ctrl+⌫ to close a tab, Esc to leave. Click works too.

    04

    Private by design

    Zero network requests. No account, no analytics. Open source, about 600 lines of plain JS.

    05

    Every window, plus more

    Searches all windows, with a small badge on tabs from other windows. Type /b for bookmarks or /h for 90 days of history, if you opt in.

    06

    Fits your browser

    Light and dark (Alt+T). A frosted glass panel with adjustable opacity, blur and size. Rebind the keys.

    // privacy

    No network requests. Ever.

    No account, no analytics, nothing leaves your browser. Plain JavaScript, no dependencies, MIT licensed. Read every line on GitHub.

    • tabsTo list and switch your open tabs.
    • activeTabTo show the overlay on the page you are on.
    • scriptingTo put the overlay on that page.
    • faviconTo show site icons, read locally.
    • storageTo save your options.
    • historyOptional. Only if you turn on /h. asks first
    • bookmarksOptional. Only if you turn on /b. asks first
